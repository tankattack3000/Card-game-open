# Card Game

En interaktiv kortlek-hemsida där du kan dra kort från högen och lägga dem varsomhelst på skärmen.

## Funktionalitet

- 🃏 Dra kort från högen
- 🎲 Kort blandas slumpmässigt
- 📱 Fungerar på både mobil och dator
- 🖱️ Drag & drop-funktionalitet

## Hur du lägger till fler kort

1. Lägg till dina kortbilder i mappen `card1/`
2. Namnge dem: `card1.png`, `card2.png`, `card3.png`, osv.
3. Uppdatera siffran i `script.js` i variabeln `NUM_CARDS` för att matcha antalet kort

## Komma igång

Öppna `index.html` i din webbläsare för att spela!

## Struktur

```
card-game/
├── index.html
├── style.css
├── script.js
└── card1/
```
